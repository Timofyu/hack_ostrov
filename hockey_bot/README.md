# Хоккейный бот для постов

Telegram-бот собирает превью матча и текст поста для канала. Картинка — вертикальный постер 4:5: чёрное поле, кислотный цвет хозяев, счёт, периоды, шайбы и нижняя плашка. Если фото нет, бот собирает то же превью из типографики.

## Запуск

Бот живёт в Telegram, а картинку собирает у тебя на компьютере. Сам браузер открывать не нужно: подойдёт любой уже установленный — Chrome, Edge, Яндекс Браузер, Brave, Opera или Firefox.

Нужен Python 3.11+.

```bash
cd hockey_bot
python -m venv .venv
```

Windows:

```bat
.venv\Scripts\activate
pip install -r requirements.txt
copy .env.example .env
python bot.py
```

macOS и Linux:

```bash
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
python bot.py
```

В `.env` впиши токен от [@BotFather](https://t.me/BotFather):

```
BOT_TOKEN=123:abc
```

`ALLOWED_USER_IDS` можно оставить пустым, тогда бот ответит любому. Если браузер установлен, но бот его не видит, укажи путь в `BROWSER_PATH`.

Пока окно с `python bot.py` открыто, бот в Telegram онлайн. Писать ему можно с телефона, планшета и любого компьютера: это один и тот же бот. Выключишь домашний компьютер — бот замолчит. Чтобы он отвечал и с выключенным компьютером, его нужно держать на сервере, который не выключается. В папке бота для этого уже есть контейнер:

```bash
docker compose up -d --build
```

На сервере нужны Docker и файл `.env` с тем же `BOT_TOKEN`. Контейнер сам поднимается после перезагрузки сервера. Логи: `docker compose logs -f`. Остановить: `docker compose stop`.

## Как постить

Напиши боту встречу и дату одной строкой:

```
Авангард ЦСКА 5 ноября 2026
```

Порядок клубов любой. Бот найдёт игру в календаре КХЛ и откроет протокол, в том числе матч прошлого сезона и плей-офф: `Локомотив Ак Барс 21 мая 2026`. Год можно не писать, если день ближе к сегодняшнему. Фото берётся из официального телеграм-канала хозяев или гостей, и для старого матча тоже: бот листает канал до даты игры. Кадр трансляции КХЛ остаётся только если клуб ничего не выложил. Сверху фото, на нём турнир, дата и автор решающей шайбы, ниже счёт и протокол. Подпись под фото — текст для канала. Кнопка «Опубликовать в канал» отправляет это же фото и этот текст.

Подойдут и такие строки: `ЦСКА — Авангард 05.11.2026`, `Салават Юлаев Лада 4 ноября`.

Ручной пост по-прежнему доступен:

1. `/match` или кнопка «Новый матч», затем только имя хозяев.
2. Клуб можно написать словами: бот знает клубы КХЛ и подставляет цвета. «СКА» не путается с «ЦСКА».
3. Дальше счёт, дата, периоды, шайбы, плашка, сноска и фото. Любой необязательный шаг пропускается.
4. Либо на первом шаге «Одним сообщением» и вставь блок:

```
Салават Юлаев — Лада
5:0
4 ноября · Уфа-Арена
2:0, 1:0, 2:0

03:33 Родуолд — Кулик, Ремпал
50:14 Ремпал — Родуолд | мен
55:43 Ремпал — Жаровский, Цулыгин | бол

Бочаров | 33 сейва | Шатаут
33-й в карьере | | первый в сезоне

Серия из трёх поражений прервана
```

Бот присылает картинку и подпись. У ручного поста подпись берётся из основного шаблона. У поста с сайта КХЛ подпись — это протокол матча.

## Шаблоны

`/templates`

Встроенные: «Итог матча», «Коротко», «Сухарь», «Анонс». Свой шаблон можно создать, встроенный — скопировать и поменять. Анонс не спрашивает счёт и рисует VS.

Пустое поле убирает строку, где оно единственное. Поля:

| Поле | Что подставится |
| --- | --- |
| `{home}` `{away}` | названия клубов |
| `{home_city}` `{away_city}` | города |
| `{score}` | `5:0` |
| `{date}` `{arena}` `{when}` | дата, арена или обе через точку |
| `{periods_line}` | `Периоды: 2:0, 1:0, 2:0` |
| `{goals_block}` | список шайб |
| `{scorers}` | авторы, повтор помечен как `×2` |
| `{goalie_line}` | нижняя плашка одной строкой |
| `{note}` | сноска |
| `{tournament}` | надпись в углу превью |

Надпись турнира меняется в шаблонах, по умолчанию `КХЛ · 26/27`.

## Канал

Добавь бота в канал администратором с правом публиковать сообщения и пришли `/channel @имя_канала`. После превью появится кнопка «Опубликовать в канал». Снять привязку: `/channel off`.
