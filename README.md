# 🏨 Агентная система «О!дин шаг до идеального отеля» (Островок)

Прототип мультиагентной системы для сбора уникальных характеристик отелей из открытых геоданных и ответов отельеров. Проект позволяет находить отели по нестандартным запросам пользователей.

## 🌟 Реализованные задачи
* **Сбор характеристик по геоданным:** Вычисление реального времени пути пешком до пляжа с учетом перепада высот и рельефа (модифицированная функция Тоблера на базе графов OSMnx).
* **Диалог с отельером:** Агент автоматически формулирует вопросы (например, про шумоизоляцию), если данных нет в открытых источниках, и структурирует полученный ответ.
* **Хранение и достоверность:** Каждое значение хранится с указанием источника (`source`), уровня уверенности агента (`confidence`) и точной даты получения (`timestamp`).
* **Расширяемость:** Объектно-ориентированная архитектура (ООП) позволяет добавлять новые характеристики без изменения схемы хранения.
* **Пользовательский интерфейс:** Простой и быстрый UI на базе Streamlit для демонстрации работы системы.

## 🛠 Технологический стек
* **Python 3.10+**
* **Streamlit** (веб-интерфейс)
* **OSMnx / NetworkX** (парсинг геоданных и графовые алгоритмы маршрутизации)
